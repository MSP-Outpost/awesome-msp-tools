# Contributing

Thanks for helping keep this list accurate and useful for MSPs.

## Suggest a Tool

1. **List it on MSP Outpost.** Every entry here links to a listing on [mspoutpost.com](https://mspoutpost.com/tools). Vendors can submit a tool through [mspoutpost.com/contribute](https://mspoutpost.com/contribute).
2. **Open an issue.** Use the Suggest a Tool form to tell us about a tool we are missing.
3. **Open a pull request.** If the tool already has an MSP Outpost listing, add it yourself.

## Pull Request Guidelines

- One tool per pull request.
- Use the format `- [Tool Name](https://mspoutpost.com/tools/...): Short factual description.`
- Put the entry in the matching category, in alphabetical order.
- Keep descriptions short, factual and free of marketing claims.
- Update `data/tools.json` to match the README.
- Check your spelling and that links work.

## Corrections

Spot wrong or outdated information? Open a Correction issue with a public source.

By contributing you agree to the [Code of Conduct](CODE_OF_CONDUCT.md) and to release your contribution under [CC0 1.0](LICENSE).
